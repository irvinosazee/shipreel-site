straight answers.

There's a free tool called /brag. How is this different?

shipreel is a fork of /brag by Shunit Haviv Hakimi, and that project is good — if it does what you need, use it, it's free. The difference is what sits on top. /brag is a prompt and a set of assets telling an agent how to make one landscape video. shipreel verifies what comes out, reflows one plan across five frame sizes and 26 platforms, captures your running interface, cites on-screen claims to files in your repo, and adds release videos, PR previews, a GitHub Action and a standalone CLI. One script and no tests became 36 scripts and 234.

Does my code leave my machine?

No. It reads your repo and renders locally; there is no shipreel server and no account. shipreel itself sends nothing. Be aware that the tools it drives have their own behaviour: Hyperframes is fetched from npm to render and reports anonymous usage of its own, and live-metrics mode calls GitHub or npm because you asked it to.

Can I use the videos commercially?

Yes — no royalty, no watermark, no credit to shipreel required. The bundled music is CC BY 4.0 by Sascha Ende, so credit him if you use it; every launch kit writes that line into credits.txt for you. Sound effects are CC0 by Kenney. Don't register a render that contains the music with YouTube Content ID — that licence forbids it.

What am I licensed to do?

Use and modify it, forever, for one developer or for everyone at one company. You can't redistribute or resell the source, or run it as a competing hosted service. Two carve-outs override that: the upstream MIT portions stay MIT, and the bundled audio keeps its own licence.

What if it breaks?

It drives Hyperframes, FFmpeg and Chrome, which move independently of it, so it can. A nightly job renders a real composition against the current Hyperframes, so breakage shows up within a day rather than when you need a video. If it's broken for you, say so; if it's unusable, take the refund.

Do I need Claude Code?

No. The CLI reads your package metadata, README and git history, captures your site, and fills a clean template with no agent at all. An agent writes something made for your project instead of a filled-in template, which is better — but it isn't required.

Where do I buy it?

Right now, by asking — the checkout isn't live, so the buttons open a message form. You'll get the tarball, the install instructions and the licence back by email.
